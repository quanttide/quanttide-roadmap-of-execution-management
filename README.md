# 量潮执行管理路线图

执行管理领域的路线图档案库，记录**演化过程**——怎么一步步从现状走向意图。它回答「怎么走、按什么顺序」，上承意图（我们要什么），下接现状（发生了什么）。

## 项目结构

```
quanttide-roadmap-of-execution-management/
├── index.md        # 路线图入口
├── intro/          # 演化过程：from-X-to-Y / 演化叙事
├── myst.yml        # MyST 文档站配置
├── README.md       # 仓库入口
├── AGENTS.md       # 目录与维护约定
└── .github/workflows/deploy-oss.yml   # 云端连接（发布到 OSS 文档站）
```

## 关联档案

- 意图（我们要什么、为什么）：`data/intention`
- 洞察（为什么这样设计成立）：`data/insight`
- 现状事实与进展：`data/profile`
